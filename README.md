# Lumin Advisory — Website

Next.js 14 + Tailwind. One-page marketing site.

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## Deploy (Vercel)
- Create a new Vercel project, import this folder (or push to GitHub and import).
- Framework preset: **Next.js** (auto-detected).
- Environment vars: none required.
- Set a custom domain if you have one.

Alternative hosts: Netlify (Next.js adapter), Cloudflare Pages.
